# zeta
A single html file to [look around beautiful Riemann zeta function](https://t7saeki.github.io/zeta/) just for fun!

This contains hard-coaded numerical data of Riemann zeta function generated by using a fortran code developed by [sikino](https://slpr.sakura.ne.jp/qp/). The data were rounded to reduce the file size. Therefore, the accuracy is worse than sikino's original result.
